오늘 — AI 제안형

가정: 사용자는 영상을 “편집”하고 싶어하지 않는다. 찍어두기만 하면 AI가 만들 만한 조합을 먼저 찾아서 대령하고, 사용자는 고르기만 한다. 홈은 라이브러리가 아니라 오늘 만들 거리의 큐다.

탭 구성

오늘·스냅·● 촬영·무비·나

홈 이름을 “오늘”로 두는 이유 — 이 화면의 내용물이 라이브러리가 아니라 “오늘 시점의 제안”이기 때문. 날짜가 바뀌면 내용이 갈린다.

무비를 만드는 두 경로

오늘→제안 카드 [만들기]→생성→무비 상세
스냅→선택 (최대 10)→무비 만들기→생성

강점 / 리스크

  • 첫 무비까지 탭 2번. 창작 진입 장벽이 가장 낮다.
  • AI가 눈에 보이는 주인공이 된다 — 제품 정체성이 선명하다.
  • 쌓인 스냅이 자동으로 소진돼서 라이브러리가 죽지 않는다.
  • 제안 품질 = 제품 품질. 묶음이 엉성하면 곧바로 신뢰를 잃는다.
  • 스냅 0개일 때 홈이 완전히 비어버린다(콜드 스타트).
  • 사용자가 “내가 만든 것” 감각을 덜 느낄 수 있다.

백엔드에 필요한 것

  • 제안 API — 스냅 메타(시각·위치·태그·유사도)로 묶음 후보 N개 생성.
  • 합성 잡 — POST /movies (snapIds ≤ 10, style) → jobId → 상태 폴링 → 렌더 URL.
  • 재생성 시 동일 스냅 세트로 seed만 바꾸는 경로.
